# Advanced controls

This page explains how the advanced props change the generated image. The examples are not presets. Each comparison uses the same seed and palette, then changes one setting so the visual effect is easy to see.

## First: the reference direction

The soft gradient references in this project have four useful traits:

1. Large color masses rather than small spots.
2. Strong overlap between sources.
3. Very soft transitions.
4. Visible but fine grain across the whole image.

![Soft gradient field generated by the package](../docs-assets/gradient-reference.svg)

```tsx
<GenerativeVisual
  seed="docs-reference"
  colors={["#FF3B00", "#FF8C00", "#D8EF18", "#E91E13"]}
  sourceCount={4}
  sourceSize={1.08}
  separation={0.16}
  blur={0.94}
  distortion={0.18}
  contrast={0.62}
  grainAmount={0.86}
  grainSize={0.78}
  vignette={false}
/>
```

This is the closest direction the current model provides to that reference style. It is not a pixel-for-pixel recreation: the generator is based on a small set of seeded elliptical sources, displacement filters, blur, and grain.

## How to read the controls

There are two layers of controls:

- Core controls describe a general visual direction.
- Advanced controls override the related core mapping.

For example, `softness` normally derives both `sourceSize` and `blur`. If you provide `sourceSize` or `blur`, those advanced values win for that render. The same relationship exists for `complexity` with `sourceCount` and `separation`, and for `texture` with `grainAmount` and `grainSize`.

Keep the seed and palette fixed while tuning. Change the seed after the parameter relationship is working.

## `sourceCount`

Controls how many sources are placed in the field.

| Low count                                      | High count                                      |
| ---------------------------------------------- | ----------------------------------------------- |
| ![Three sources](../docs-assets/count-low.svg) | ![Nine sources](../docs-assets/count-high.svg)  |
| Fewer, broader compositional decisions.        | More layers and more opportunities for overlap. |

Use `3`–`4` for calm gradient fields. Use `8`–`10` for a denser, more layered surface. Count alone does not make a result noisy: blur, source size, and grain still control the finish.

## `sourceSize`

Controls the radius of each source.

| Small sources                                   | Large sources                                   |
| ----------------------------------------------- | ----------------------------------------------- |
| ![Small sources](../docs-assets/size-small.svg) | ![Large sources](../docs-assets/size-large.svg) |
| More visible gaps and local shapes.             | Wider masses and stronger overlap.              |

Pair it with `separation`:

- Small size + high separation creates distinct islands.
- Large size + low separation creates one connected field.

The usable range is `0.35` to `1.15`.

## `separation`

Controls the minimum distance between source centers. It changes composition before blur is applied.

| Close sources                                                | Far sources                                              |
| ------------------------------------------------------------ | -------------------------------------------------------- |
| ![Close source centers](../docs-assets/separation-close.svg) | ![Far source centers](../docs-assets/separation-far.svg) |
| Clustered, blended, continuous.                              | Spaced, open, more individually legible.                 |

Use low values for the reference-like gradient direction. Use high values when the image needs clear regions instead of one merged mass.

## `blur`

Controls the Gaussian blur applied after each source is displaced.

| Low blur                                            | High blur                                          |
| --------------------------------------------------- | -------------------------------------------------- |
| ![Low blur](../docs-assets/blur-low.svg)            | ![High blur](../docs-assets/blur-high.svg)         |
| Keeps edges, deformation, and local shapes visible. | Removes edges and creates broad tonal transitions. |

For soft gradients, start around `0.8`–`1.0`. For graphic or ink-like forms, start around `0.1`–`0.3`.

## `distortion`

Controls the displacement strength before blur.

| Low distortion                                       | High distortion                                        |
| ---------------------------------------------------- | ------------------------------------------------------ |
| ![Low distortion](../docs-assets/distortion-low.svg) | ![High distortion](../docs-assets/distortion-high.svg) |
| Sources stay close to elliptical shapes.             | Contours become irregular and turbulent.               |

High distortion is not the same as high detail. If blur is also high, much of the contour change will disappear into the soft transition.

## `grainAmount` and `grainSize`

Grain is applied over the whole field, not separately to each source.

| Clean surface                                  | Heavy surface                                  |
| ---------------------------------------------- | ---------------------------------------------- |
| ![Clean grain](../docs-assets/grain-clean.svg) | ![Heavy grain](../docs-assets/grain-heavy.svg) |
| `grainAmount: 0.08`, `grainSize: 0.35`         | `grainAmount: 0.96`, `grainSize: 0.78`         |

`grainAmount` controls visibility. `grainSize` controls frequency:

- Higher amount makes texture more obvious.
- Lower size makes larger, softer noise patches.
- Higher size makes finer, more photographic noise.

For a tactile gradient, raise both moderately. For a clean digital surface, lower `grainAmount` first.

## `contrast`

Controls the opacity of light, dark, and palette-colored source roles.

| Low contrast                                     | High contrast                                      |
| ------------------------------------------------ | -------------------------------------------------- |
| ![Low contrast](../docs-assets/contrast-low.svg) | ![High contrast](../docs-assets/contrast-high.svg) |
| Quiet transitions and less separation.           | Stronger anchors and clearer tonal structure.      |

Contrast is often the fix when a palette feels muddy. It does not change the palette itself.

## `vignette`

Adds a dark radial layer at the edges. It does not change source placement, blur, or grain.

Use `vignette` when the visual needs a framed or cinematic edge. Leave it off when the gradient should reach the corners evenly.

## Configuration recipes

These are starting points, not named presets.

### Soft gradient field

```tsx
{
  sourceCount: 3,
  sourceSize: 1.1,
  separation: 0.15,
  blur: 0.95,
  distortion: 0.15,
  contrast: 0.6,
  grainAmount: 0.8,
  grainSize: 0.75,
  vignette: false,
}
```

### Distinct color masses

```tsx
{
  sourceCount: 6,
  sourceSize: 0.68,
  separation: 0.65,
  blur: 0.22,
  distortion: 0.5,
  contrast: 0.9,
  grainAmount: 0.55,
  grainSize: 0.5,
}
```

### Dense and rough

```tsx
{
  sourceCount: 9,
  sourceSize: 0.58,
  separation: 0.58,
  blur: 0.16,
  distortion: 0.72,
  contrast: 0.94,
  grainAmount: 0.92,
  grainSize: 0.7,
  vignette: true,
}
```

## Translating a verbal brief

Map a description to a group of controls instead of changing one slider at random:

| Brief                         | Start with                                                 |
| ----------------------------- | ---------------------------------------------------------- |
| soft, hazy, atmospheric       | low count, large size, low separation, high blur           |
| clean, spacious, minimal      | low count, high separation, medium blur, low grain amount  |
| rough, tactile, printed       | medium/high grain amount, high grain size, medium contrast |
| sharp, graphic, separated     | high contrast, low blur, high separation, medium size      |
| turbulent, organic, irregular | high distortion, medium blur, medium/high count            |
